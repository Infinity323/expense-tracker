# Expense Tracker

A personal expense-tracking web application. Built with React.js, Express, Node.js, and PouchDB.

Account transaction data provided by the [Plaid API](https://plaid.com/docs/).

## How to Run

```bash
# ./client
npm start

# ./server
tsx server.ts
```
